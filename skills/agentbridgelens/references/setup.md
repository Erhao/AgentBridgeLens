# 首次连接与排障

仅在用户尚未连接或连接失败时阅读。告诉用户：“需要让 AI 和你的 Chrome 连起来：Chrome 装一个扩展，AI 端连接配套服务。连好后直接说哪里有问题就行。”

先从环境判断客户端和机器位置；无法判断时只问关键缺项：“你用哪个 AI 软件？Chrome 和运行 AI 的程序是不是在同一台电脑？” 手机聊天界面不代表二者在同一台设备。

## 同机连接

1. **Chrome 扩展**：优先使用推广者提供的扩展压缩包。解压后打开 `chrome://extensions/`，打开右上角“开发者模式”，选择“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录，不选 zip 文件。
2. **AI 服务**：检查现有 MCP 配置，保留其他服务及已有设置。支持 stdio 的客户端可以添加以下服务器定义；具体入口和路径依客户端实际情况确定，不猜路径：

   ```json
   {
     "mcpServers": {
       "bridgelens": {
         "command": "npx",
         "args": ["-y", "agentbridgelens"]
       }
     }
   }
   ```

   需要运行 AI 的机器可以使用 Node.js/npm 并访问包源，先检查已有条件，不让新手重复安装。也可使用本地构建：命令为 `node`，参数为真实的 `packages/bridge/dist/index.js` 绝对路径，不照抄其他机器路径。
3. **重载连接**：客户端重新加载 MCP 配置，必要时重启。Chrome 点 AgentBridgeLens 图标，同机默认 Host 为 `127.0.0.1`、Port 为 `19222`；未配置密钥时 Token 留空。点“保存并重连”，查看是否“已连接”。stdio 模式由客户端启动服务，无需再手动启动一个进程抢占端口。
4. **第一次成功**：打开普通网页，调用 `get_page_info` 确认标题，再截图。拿到正确结果后才说“已经能看到这个页面了”。不能仅凭写入配置就报告成功。

## 没有扩展包

不要编造商店地址、下载链接或声称已经安装。若工作区是 AgentBridgeLens 源码，可检查依赖后在根目录执行 `pnpm install`、`pnpm zip`，将实际生成的 `agentbridgelens-extension.zip` 提供给用户。目标浏览器机器只需解压加载扩展，不需要源码或 Node.js。没有源码和包时说明还缺扩展包，向推广者索取实际文件。

## 不同机器或 URL 连接

先确认服务和 Chrome 分别在哪台机器、是否已有可用网络通道，优先利用已配置的安全隧道。需要新配置时说明在哪台机器操作。

- Chrome 扩展连接 **WebSocket 19222**。跨机直连时服务端设置 `BRIDGELENS_HOST` 和 `BRIDGELENS_TOKEN`；扩展 Host 填可访问的服务机器地址，Token 保持一致。`0.0.0.0` 是监听地址，不能当扩展目标地址。
- URL 方式连接 MCP 使用 **Streamable HTTP 19223/mcp**。服务独立运行，设置 `BRIDGELENS_TRANSPORT=http`；跨机 HTTP 还需 `BRIDGELENS_HTTP_HOST` 和 `BRIDGELENS_HTTP_TOKEN`，客户端发送 Bearer 认证。两套连接、端口分别检查。
- 原生服务是 HTTP/WS；跨不可信网络用 SSH 隧道或 TLS 代理，不明文传 Token。不为排障关闭认证或任意开放防火墙。
- URL 模式共享浏览器和目标标签页状态，并非多用户隔离；操作带明确 `tabId`。它不是旧式 SSE 连接。

## 按现象排查，一次只给当前要做的动作

| 现象 | 检查顺序 |
| --- | --- |
| AI 找不到工具 | MCP 配置是否加载；命令/路径是否可用；重载后再发现工具 |
| 扩展未连接 | 服务是否启动；Host/Port/Token 是否对应；跨机再查网络 |
| 端口占用 | 先确认已有服务，避免杀其他会话进程；确需换端口时同时修改两端 |
| 连接正常但读页失败 | 页面是否在扩展加载后打开或刷新；刷新前考虑未保存输入；浏览器内部页等受限页面换普通网页验证 |
| 查到错误页面 | `list_tabs` 确认并显式传目标 `tabId`；已有固定目标可能覆盖前台页面选择 |
| 没有日志或请求 | 开始采集后再复现，历史数据不会自动补齐 |
| 无法追到源文件 | 检查开发构建和 source map，配合本地源码搜索 |
