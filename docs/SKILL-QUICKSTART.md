# 让 AI 看懂你正在打开的网页

网页歪了？按钮点了没反应？用 AgentBridgeLens 网页小助手，再用一句话描述问题，AI 就能检查你自己 Chrome 里的页面，帮你找原因。有项目源码时，还能继续帮你修改和验证。

你不需要懂代码，也不需要记工具名。

## 安装 skill

把分发包里的 `agentbridgelens` 整个文件夹放入 AI 软件支持的 skills 目录。Codex 通常使用 `~/.codex/skills/`，安装后应有 `~/.codex/skills/agentbridgelens/SKILL.md`；保留同目录的 `agents` 和 `references` 文件夹。

重新打开会话，对 AI 说：

> 请用 $agentbridgelens 帮我连接浏览器。我完全不懂技术，请一步一步带我做。

**skill 是给 AI 的操作指南。** 还需要 AgentBridgeLens Chrome 扩展和配套连接服务；AI 会检查已有条件，带你完成缺少的部分。Chrome 扩展需另行提供，skill 包不包含扩展。

## 连好后，直接这样说

- “帮我看看当前网页，先告诉我你看到了什么。”
- “这个登录按钮点了没反应，帮我查原因。”
- “右边卡片的文字被挡住了，帮我看看。”
- “页面一直转圈，看看卡在哪里。”
- “帮我检查手机宽度下会不会有内容超出去。”
- “这个问题帮我修一下，修好后再检查一遍。”

打开要检查的网页，告诉 AI 页面标题和具体问题即可。第一次可让 AI 高亮它找到的按钮，确认双方说的是同一个地方。

尚未连接时，跟着 AI 做当前那一步。有些浏览器内部页无法检查，可以先用普通网站验证。没有对应源码时，AI 可以检查和给建议；能否直接修复取决于源码和修改权限。

## 给推广者

可分发 skill 位于 `skills/agentbridgelens/`。将整个文件夹打成 zip，把本指南和实际 Chrome 扩展包一起发给新用户。不要把 skill 包称为“一装就能控制浏览器”。

可复制的介绍：

> 不会看网页报错？试试 AgentBridgeLens 网页小助手。连接自己的 Chrome 后，直接告诉 AI“哪里有问题”，它就能看页面、查原因，有源码还能帮你修改。首次连接也可以让它一步步带你做。
